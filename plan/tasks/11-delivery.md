# Задача 11. Примеры, документация и демонстрация

## Цель

Подготовить проект к проверке и сдаче: примеры, воспроизводимый запуск, документацию и демонстрацию.

## Задачи

- Подготовить композиции «Обучение», «Финансы», «Технологии».
- Для совместимого набора показать все три формата без масштабирования.
- Написать README:
  - требования Docker и Docker Compose;
  - настройку `.env`;
  - запуск и остановку;
  - healthcheck;
  - запуск тестов;
  - формат JSON-палитры;
  - поддерживаемые браузеры;
  - ограничения.
- Описать архитектуру хранения, извлечения и переиспользования SVG.
- Перечислить AI-инструменты, использованные при разработке.
- Записать демонстрацию обоих сценариев, fallback, ручного и мобильного редактирования, импорта палитры, восстановления и экспорта.
- Проверить запуск с чистого состояния.

## Основные команды README

```bash
cp .env.example .env
# Заполнить настройки LLM при их наличии

docker compose up --build
```

```bash
# Остановка
docker compose down

# Пересборка
docker compose up --build --force-recreate

# Просмотр логов
docker compose logs -f web

# Запуск Django-тестов
docker compose run --rm web python manage.py test
```
