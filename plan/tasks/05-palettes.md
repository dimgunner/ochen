# Задача 05. Встроенные и пользовательские палитры

## Цель

Реализовать автоматическую перекраску сцены встроенными и загружаемыми JSON-палитрами с соблюдением цветовых ограничений.

## Задачи

- Описать Purple, Warm и Aqua в JSON.
- Реализовать перекраску сцены по ролям.
- Реализовать JSON Schema пользовательской палитры: название, 4 цвета фона и 4 цвета объектов.
- Добавить загрузку `.json` файла.
- Проверять обязательные поля, количество цветов, HEX-формат, роли и допустимые значения.
- Показывать ошибки файла без изменения текущей сцены.
- Подготовить принятые пользовательские палитры к сохранению в IndexedDB.
- Проверять запрет объектных цветов в фоновых ролях.
- Сохранять цветной вид главных и монохромный вид фоновых объектов.

## Зависимости

- Задачи 01 и 03.

## Оценка

**1–1,5 человеко-дня.**

## Критерии приёмки

- Все встроенные схемы перекрашивают всю сцену одним действием.
- Корректный пользовательский JSON добавляет новую схему.
- Некорректный файл отклоняется с конкретным сообщением.
- Повторная смена схем не накапливает ошибки.
- Перекраска не меняет позиции, повороты, размеры и геометрию.
- Новая встроенная схема добавляется данными без изменения алгоритма.
- Импорт палитры работает в desktop и мобильных браузерах.
