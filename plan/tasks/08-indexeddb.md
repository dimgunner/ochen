# Задача 08. Автосохранение в IndexedDB

## Цель

Сохранять одну текущую сцену и пользовательские палитры локально с восстановлением после перезагрузки.

## Задачи

- Создать версионированную схему локальных данных.
- Сохранять текущую сцену с debounce.
- Сохранять пользовательские палитры.
- Восстанавливать состояние после перезагрузки.
- Хранить только ссылки на `assetId`, не дублируя исходные SVG.
- Обрабатывать повреждённые и устаревшие данные.
- Добавить сброс текущей сцены.

## Зависимости

- Стабильная модель после задач 03–05.

## Оценка

**0,5–0,75 человеко-дня.**

## Критерии приёмки

- После перезагрузки восстанавливаются объекты, позиции, повороты, слои, формат, L/S и палитра.
- Исходные SVG не дублируются в IndexedDB.
- Повреждённые данные не ломают запуск; пользователь может сбросить состояние.
- Backend не участвует в сохранении сцен.
- Восстановление работает в desktop и мобильных Chrome и Firefox.
