# Задача 06. Автоматическая компоновка без масштабирования

## Цель

Автоматически размещать 1–3 главных объекта и фоновые элементы в выбранном формате без изменения исходных размеров.

## Задачи

- Подготовить шаблоны для 1–3 главных объектов и фоновых элементов.
- Учитывать формат, L/S и intrinsic-размеры.
- Рассчитывать только позиции, повороты и z-order.
- Проверять границы объектов с учётом поворота.
- Предотвращать существенные перекрытия главных объектов.
- Разрешать контролируемые перекрытия и обрезку фоновых объектов и декора.
- Реализовать предварительную проверку совместимости набора с форматом.
- При невозможности размещения возвращать понятную ошибку.
- Реализовать перестроение под другой формат без изменения размеров.

## Зависимости

- Задачи 03 и 04.

## Оценка

**1–1,5 человеко-дня.**

## Критерии приёмки

- Подходящий набор размещается без ручной расстановки.
- Ни один объект не масштабируется.
- Главные объекты полностью находятся внутри холста.
- Относительные размеры объектов остаются исходными.
- Непомещающийся набор не создаёт некорректную сцену.
- Ошибка предлагает S, другой формат или уменьшение количества объектов.
- Совместимый набор можно перестроить под другой формат.
