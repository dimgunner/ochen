# Задача 06. Автоматическая компоновка

## Цель

Автоматически размещать композицию в выбранном формате без изменения исходных
размеров объектов. Планировщик должен подбирать лучшую раскладку для любого
количества главных объектов: 1, 2, 3, 4, 5+.

## Задачи

- Перебирать варианты сетки: от одной колонки до одного ряда.
- Для каждого варианта считать ширину, высоту и требуемый общий масштаб.
- Выбирать вариант с максимальным масштабом.
- Учитывать формат при равенстве вариантов:
  - широкий формат — больше колонок;
  - портретный — больше строк;
  - квадрат — сетка, ближайшая к `sqrt(n)`.
- Центрировать весь блок, каждую строку и объект внутри строки.
- Поддерживать 1–3 главных объекта для автоматической генерации и любое
  количество для ручной сборки.
- Для ручной сборки с 4+ объектами применять сетку при «Автокомпоновке»,
  смене формата и генерации.
- Не перекладывать сцену при ручном добавлении объекта: новый объект ищет
  свободное место, существующие остаются на месте.
- Учитывать формат, L/S и intrinsic-размеры.
- Рассчитывать только позиции, повороты и z-order.
- Проверять границы объектов с учётом поворота.
- Предотвращать существенные перекрытия главных объектов.
- Разрешать контролируемые перекрытия и обрезку фоновых объектов и декора.
- Реализовать предварительную проверку совместимости набора с форматом.
- При невозможности размещения возвращать понятную ошибку.
- Реализовать перестроение под другой формат без изменения размеров.

## Зависимости

- Задачи 03 и 04.

## Оценка

**2–3 человеко-дня.**

## Критерии приёмки

- Подходящий набор размещается без ручной расстановки.
- 3 крупных L-объекта в `1000x1000` не требуют масштаба 29%.
- 4 объекта в квадратном формате раскладываются в сетку 2x2.
- В портретном формате используется вертикальная компоновка или 2+1.
- Главные объекты полностью находятся внутри холста.
- Главные объекты не перекрываются существенно.
- Отдельные объекты не масштабируются; применяется один общий коэффициент
  масштаба композиции, сохраняющий относительные размеры.
- Фоновые объекты остаются позади главных и могут обрезаться.
- Ручное добавление объекта не сдвигает и не поворачивает существующие объекты.
- Непомещающийся набор не создаёт некорректную сцену.
- Ошибка предлагает S, другой формат или уменьшение количества объектов.
- Совместимый набор можно перестроить под другой формат.
