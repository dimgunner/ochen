# Задача 04. Редактор композиции

## Цель

Реализовать ручное редактирование сцены на desktop и mobile без масштабирования объектов.

## Задачи

- Реализовать выделение объекта на холсте и в панели слоёв.
- Добавить drag-and-drop перемещение.
- Добавить поворот вокруг центра объекта.
- Реализовать дублирование и удаление.
- Реализовать управление слоями: вперёд/назад, на передний/задний план и изменение порядка в панели.
- Реализовать преобразование экранных координат в SVG-координаты.
- Пересчитывать bounding box после поворота для проверки границ.
- Использовать Pointer Events для мыши, touch и stylus.
- Реализовать сенсорное перемещение и удобный сенсорный поворот.
- Увеличить области нажатия мобильных элементов управления.
- Предотвращать прокрутку страницы во время активного жеста.
- Обрабатывать отмену жеста и потерю pointer capture.
- Не добавлять элементы управления размером.

## Зависимости

- Задача 03.

## Оценка

**1,5–2 человеко-дня.**

## Критерии приёмки

- Все разрешённые операции доступны мышью и касанием.
- Перемещение работает корректно при любом zoom отображения редактора.
- На мобильном устройстве страница не прокручивается вместо перемещения объекта.
- Поворот не меняет размеры и геометрию объекта.
- Все операции доступны без hover и клавиатуры.
- Масштабирование отсутствует в UI и модели сцены.
- Порядок слоёв совпадает с визуальным порядком.
- Дублирование и удаление не затрагивают исходный ассет.
