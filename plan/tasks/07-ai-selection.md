# Задача 07. AI и оба сценария подбора

## Цель

Реализовать автоматический подбор по метафоре/заголовку и по явному списку компонентов с последующей компоновкой сцены.

## Задачи

### Метафора или заголовок

- Передавать в LLM только каталог разрешённых объектов и пользовательский текст.
- Запрашивать строгий JSON с `assetId`, `role` и кратким обоснованием.
- Проверять JSON Schema и whitelist.
- Отклонять неизвестные ID и роли.
- Ограничивать результат тремя главными объектами.
- Добавить timeout, обработку ошибок и повторный запрос.
- Реализовать локальный fallback по тегам и синонимам.
- Хранить настройки LLM в переменных окружения Django: `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`.

### Явный список

- Поддержать ввод нескольких названий.
- Добавить регистронезависимость и синонимы.
- Обрабатывать неизвестные и неоднозначные названия.
- Передавать распознанный набор в layout engine.

## Зависимости

- Задачи 01, 02 и 06.

## Оценка

**1,5–2 человеко-дня.**

## Критерии приёмки

- Оба сценария заканчиваются готовой сценой либо понятной ошибкой совместимости.
- AI выбирает только существующие объекты и роли.
- AI не управляет координатами, размерами и SVG.
- Неизвестные ID и названия не приводят к добавлению произвольных объектов.
- При недоступном API работает локальный fallback.
- Текущая сцена не теряется при ошибке AI.
- Тесты используют mock LLM и не зависят от сети.
- LLM proxy корректно работает внутри Docker Compose.
