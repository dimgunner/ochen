# Задача 00. Подготовка и технические проверки

## Цель

Проверить готовность исходных данных и ключевые технические риски до начала основной разработки.

## Задачи

- Проверить целостность локального набора из 40 SVG-вариантов в `misc/figma-task/library/Библиотека компонентов`.
- Проверить полный цикл на сложном объекте: `SVG → Vue/SVG DOM → поворот → перекраска → экспорт`.
- Проверить выбранный OpenAI-compatible API и structured JSON response.
- Проверить SVG-экспорт в Chrome и Firefox.
- Создать структуру репозитория и конфигурацию окружения.
- Подготовить `.env.example` с `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`.

## Зависимости

- Локальная библиотека SVG.
- Параметры LLM API для проверки основного AI-сценария.

## Оценка

**0,5 человеко-дня.**

## Критерии приёмки

- Все 40 SVG-файлов доступны и читаются.
- Сложный объект проходит цикл без растеризации и потери структуры.
- LLM возвращает машинно проверяемый JSON.
- Экспортированный SVG открывается в Chrome и Firefox.
- Секреты вынесены в `.env`; репозиторий содержит только `.env.example` без реальных ключей.
